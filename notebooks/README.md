# Day-wise notebooks

Each day has its own folder:

```text
notebooks/day01/
├── CONCEPTS.md          ← read before the notebook
└── day01_....ipynb
```

Open the `.ipynb` for that day in Jupyter. The notebook uses `find_project_root()` so paths work when the kernel cwd is `notebooks/dayXX/`.
