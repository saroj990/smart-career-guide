# Day 5 — First classification model (baseline)

## Goal
Train **logistic regression** as a simple, interpretable baseline for multi-class `Career`.

## Key ideas
- **Baseline:** cheap model to beat; sanity-check pipeline.
- **Metrics:** accuracy, precision, recall, F1, confusion matrix.
- **Multi-class:** one career per row; model outputs class probabilities.
