# Day 8 — Artificial neural network (ANN)

## Goal
Build a small **feed-forward** network with softmax output for multi-class careers.

## Key ideas
- **Layers:** input → hidden (ReLU) → output (softmax).
- **Epochs / batch size:** how long and how much data per update.
- **Dropout / early stopping:** reduce overfitting.
- Plot train vs validation loss and accuracy.
