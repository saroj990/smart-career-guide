# Day 4 — K-Means clustering

## Goal
Group students by **similar profiles** (unsupervised) — not to predict career directly, but to explore structure.

## Key ideas
- **K:** number of clusters; try several values.
- **Elbow method:** plot inertia vs K; look for an “elbow”.
- **Silhouette score:** higher = better-separated clusters.
- **Scaling required** before distance-based clustering.

## Checkpoint
Why use clustering if it does not directly output a career?

## Before Day 5
Cluster labels can be added as an optional feature later, but career prediction is still **supervised** from Day 5 on.
